# JavierArenasVillanueva TFM

Código asociado al TFM “Estudio de la expresión génica vinculada al grado histológico en tumores de mama”, del Máster en Data Science de la UOC, curso 2025-2026.

## Archivos del repositorio

- `JavierArenasVillanueva_TFM.Rmd`: archivo principal en R Markdown con el código utilizado para la descarga de datos, preparación, corrección del efecto de lote, análisis exploratorio, selección de características, entrenamiento de modelos y validación externa.
- `JavierArenasVillanueva_TFM.html`: versión renderizada del archivo R Markdown, que permite visualizar el análisis y sus resultados sin necesidad de ejecutar el código.

## Datos

Los datos utilizados proceden de GEO (*Gene Expression Omnibus*) y se descargan desde el propio código. Los conjuntos empleados son GSE4922 y GSE2990, ambos sobre la plataforma GPL96.
